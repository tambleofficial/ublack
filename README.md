# U.BLACK 유블랙 — Cloudflare Pages 배포

1. 이 폴더 전체를 GitHub 저장소 루트에 업로드합니다.
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → 저장소 선택.
3. 프로젝트 이름: `ublack` → 주소 https://ublack.pages.dev
4. Build settings: Framework preset **None**, Build command **비움**, Build output directory **/** (루트).
5. Save and Deploy.

배포 후 Google Search Console / 네이버 서치어드바이저에 `https://ublack.pages.dev/sitemap.xml`, `https://ublack.pages.dev/rss.xml`을 등록하세요.
